# Procedury

Jedna procedura to jeden plik, nazwa opisuje zadanie, np. `publikacja-strony.md`. Procedurę piszesz po drugim wykonaniu tego samego zadania. Gdy w trakcie pracy okaże się, że procedura ma błąd, poprawiasz ją od razu i dopisujesz lekcję.

Szablon:

```
# <Nazwa zadania>
Właściciel procedury: <rola>
Ostatnia zmiana: RRRR-MM-DD, powód: <...>

## Kiedy używać
## Kroki
1. ...
## Jak sprawdzić, że się udało
## Znane pułapki (z wiedza/lekcje.md)
```
