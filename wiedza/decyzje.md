# Rejestr decyzji

Najnowsze na górze. Format:

```
## RRRR-MM-DD: <tytuł decyzji>
Kto: <rola lub właściciel>
Decyzja: <co postanowiono>
Dlaczego: <powód, dane>
Odrzucone opcje: <co jeszcze rozważano>
Kiedy sprawdzić: <data albo warunek>
```
